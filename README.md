📘 Persian Gulf Blockchain Whitepaper (PGB)

This repository contains the official whitepaper of the Persian Gulf Blockchain (PGB).
The whitepaper provides complete details about the network, Layer-1 architecture, project goals, token standards, and the vision for the cultural–sports ecosystem.

Files include the official PDF and an editable Markdown version, giving developers and enthusiasts easy access to technical information.
